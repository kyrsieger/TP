# 术语表

产品文案、设计稿、代码命名和其他文档统一使用以下术语。具体规则见[产品设计](DESIGN.md)。

| 术语 | 含义 |
| --- | --- |
| TP | 本应用名称，取自“传送”的意象：把内容从电脑上的一处送到另一处。应用标志由悬浮菱形光束与椭圆传送环组成。 |
| 面板 | 唤出工具后用于浏览和应用历史记录的界面，不包括设置界面及托盘或菜单栏入口。 |
| 主题配色 | 控制主面板、设置及两个预览窗口的背景、强调色和文字颜色的设置；悬停立即切换并自动记忆最后一项。 |
| 字号 | 外观模块中位于字体上方的文字大小设置；默认 14，范围 10–20 的整数，按比例调整各窗口文字并保留大小层次。 |
| 界面字体 | “字号”下方的全局字体设置；同一完整家族的不同粗细和倾斜样式合并为一项，选择后应用于主面板、设置及两个预览窗口。“系统默认”沿用原有字体。 |
| 字重（字体样式） | 字体家族内实际安装的 Regular、Light、Bold、Italic 等变体；在“字体”下方单独选择，与家族一起保存。切换家族优先使用 Regular。 |
| 字体拼音搜索 | 在字体下拉中，用拼音首字母或无声调全拼查找中文字体，例如 `XW` 查找“霞鹜文楷”；同时支持原始名称及系统提供的英文别名。 |
| 主题色条 | 主题触发按钮和下拉主题项中，由强调色、面板背景、浮层表面、控件背景、选中背景、正文和次要文字七个色块按明度从深到浅组成的色条。 |
| 保留搜索框输入 | 默认开启的设置；开启时面板隐藏后保留搜索词，关闭时每次隐藏面板都清空搜索词。 |
| 保留类型筛选 | 默认开启的设置；开启时面板隐藏后保留所选内容类型，关闭时每次隐藏面板都将类型筛选恢复为“全部”。 |
| 在任务栏显示图标 | Windows 默认开启的设置；决定主面板显示或最小化时是否显示 TP 任务栏图标，与系统托盘入口独立。 |
| 后台常驻 | 默认关闭的设置；开启后主面板隐藏时持续保留窗口、列表与已加载图片，不执行闲置清空或主动挂起，唤出时先显示保留内容再同步最新记录，以更多内存换取更快唤出。 |
| 窗口闲置释放 | 预览窗口隐藏 30 秒后销毁，再次使用时重新创建；主面板未开启“后台常驻”时采用闲置挂起；后台剪贴板记录与托盘入口继续运行。 |
| 主面板闲置挂起 | 未开启“后台常驻”时，主面板隐藏后保留内容 1 分钟；持续隐藏满 1 分钟时先清空列表、图片和记录快照，确认清空完成后再尝试暂停页面运行，保留窗口和必要环境；唤出时先恢复再读取最新记录。不等于释放全部内存分配。 |
| 低内存模式 | Windows 隐藏页面请求 WebView2 尽力减少内存占用的模式，显示前恢复正常模式；可能将部分内存换到磁盘，不保证固定降幅。 |
| 列表虚拟化 | 只为可见及邻近记录创建记录行和图片，其余位置保留滚动高度；导航与选择仍基于完整筛选结果。 |
| 系统剪贴板 | 操作系统当前提供给粘贴操作的数据，区别于本工具保存的历史记录。 |
| 移除末尾空白 | 默认开启的设置；在新复制的文本进入系统剪贴板后自动清理，并在文字、链接和颜色记录的展示与应用时移除末尾连续的 Unicode 空白（含换行、空格、制表符和不换行空格），保留中间换行及缩进，始终保存原文。记录列表不显示末尾换行提示。关闭时悬停预览显示实际末尾空行，应用时恢复原文。 |
| 历史记录 | 本工具保存的一次复制内容；一次复制多个文件仍是一条记录。 |
| 记录标题 | 用户通过记录右键菜单的“重命名”或记录重命名快捷键设置的可选名称，只用于展示与搜索，不改变原内容或磁盘文件名；清空后恢复未命名展示。 |
| 记录重命名快捷键 | 默认为 F2、可在设置中自定义或清除的局部快捷键，仅在记录列表聚焦时重命名当前记录；菜单项右侧显示当前按键。 |
| 默认视图 | 界面中名为“默认”的入口，展示全部历史记录；它不是记录的归属分组。 |
| 普通记录 | 既未收藏、也未归入自建分组的历史记录。 |
| 收藏 | 界面中展示带收藏标记记录的入口。 |
| 收藏标记 | 记录上独立于自建分组归属的标记。 |
| 记录置顶 | 让一条历史记录在所属视图中排在未置顶记录之前；与工具栏的面板置顶开关无关。 |
| 自建分组 | 用户创建的记录整理容器。 |
| 内容类型 | 记录自动识别出的文本、图片、视频、文件、链接或颜色类型；从文件夹复制的纯图片文件组合也归为图片。 |
| 列表缩略图 | 图片或视频记录在列表中使用的小图；极端长图可以裁剪以突出可识别的特征。 |
| 悬停预览 | 鼠标停在记录上或按 `→` 后于面板外显示的预览；文本文件可显示内容，纯图片或纯视频文件组合可逐项查看，图片显示最长边不超过 1440 像素的完整缩小图，视频显示完整首帧。 |
| 大图预览 | 选中图片或视频后按 `Space` 或 `←` 打开的独立预览窗，完整显示图片原图或视频首帧；纯图片或纯视频文件组合可逐项查看。 |
| 敏感记录 | 识别为从 1Password 桌面应用复制的历史记录。 |
| 最后使用时间 | 最近一次复制到该记录或从本工具应用该记录的时间。 |
| 应用记录 | 将历史记录写回系统剪贴板，并在原输入目标可用时直接粘贴。 |
| 文件副本 | 从原文件复制到本工具数据目录的文件。 |
| 路径引用 | 只保存原文件路径、不保存文件本体的文件记录。 |
| 可见序号 | 从当前最上方可见记录开始重新编号的序号，不是记录的固定 ID。 |
| 固定位置 | 面板在用户选定的位置出现的模式。 |
| 跟随光标 | 面板在光标附近出现的模式。 |
