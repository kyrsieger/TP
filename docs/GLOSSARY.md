# 术语表

产品文案、设计稿、代码命名和其他文档统一使用以下术语。具体规则见[产品设计](DESIGN.md)。

| 术语 | 含义 |
| --- | --- |
| 面板 | 唤出工具后用于浏览和应用历史记录的界面，不包括设置界面及托盘或菜单栏入口。 |
| 系统剪贴板 | 操作系统当前提供给粘贴操作的数据，区别于本工具保存的历史记录。 |
| 历史记录 | 本工具保存的一次复制内容；一次复制多个文件仍是一条记录。 |
| 默认视图 | 界面中名为“默认”的入口，展示全部历史记录；它不是记录的归属分组。 |
| 普通记录 | 既未收藏、也未归入自建分组的历史记录。 |
| 收藏 | 界面中展示带收藏标记记录的入口。 |
| 收藏标记 | 记录上独立于自建分组归属的标记。 |
| 记录置顶 | 让一条历史记录在所属视图中排在未置顶记录之前；与工具栏的面板置顶开关无关。 |
| 自建分组 | 用户创建的记录整理容器。 |
| 内容类型 | 记录自动识别出的文本、图片、视频、文件、链接或颜色类型；从文件夹复制的纯图片文件组合也归为图片。 |
| 列表缩略图 | 图片或视频记录在列表中使用的小图；极端长图可以裁剪以突出可识别的特征。 |
| 悬停预览 | 鼠标停在记录上后于面板外显示的预览；图片按窗口缩放原图，视频显示完整首帧。 |
| 大图预览 | 选中图片或视频后按 `Space` 打开的独立预览窗，完整显示图片原图或视频首帧。 |
| 敏感记录 | 识别为从 1Password 桌面应用复制的历史记录。 |
| 最后使用时间 | 最近一次复制到该记录或从本工具应用该记录的时间。 |
| 应用记录 | 将历史记录写回系统剪贴板，并在原输入目标可用时直接粘贴。 |
| 文件副本 | 从原文件复制到本工具数据目录的文件。 |
| 路径引用 | 只保存原文件路径、不保存文件本体的文件记录。 |
| 可见序号 | 从当前最上方可见记录开始重新编号的序号，不是记录的固定 ID。 |
| 固定位置 | 面板在用户选定的位置出现的模式。 |
| 跟随光标 | 面板在光标附近出现的模式。 |
