# 术语表

产品文案、设计稿、代码命名和其他文档应以本表为准。“默认”和“收藏”是界面名称；讨论数据规则时使用更精确的术语。

此前讨论中的“默认分组”统一称为**默认视图**；“收藏分组”在界面上仍叫“收藏”，在数据规则中称为**收藏标记**。

“面板”只指唤出工具后显示的界面，浏览记录、搜索、筛选、应用记录、位置、大小和置顶规则都在面板内发生；设置界面、托盘或菜单栏入口不称为面板。

| 术语 | 定义 | 避免混用 |
| --- | --- | --- |
| 面板 | 唤出工具后显示的界面，用于浏览和筛选历史记录并应用记录。 | 设置界面、托盘或菜单栏入口 |
| 系统剪贴板 | 操作系统当前提供给粘贴操作的数据。它与本工具保存的历史记录分别管理。 | 历史记录 |
| 历史记录 | 本工具保存的一次复制内容；一次复制多个文件也只产生一条记录。再次复制相同内容时按去重规则更新现有记录。 | 系统剪贴板条目 |
| 默认视图 | 界面中名为“默认”的入口，展示全部历史记录，包括已收藏和已归入自建分组的记录。它不是记录的数据归属分组。 | 普通记录、自建分组 |
| 普通记录 | 既未收藏、也未归入自建分组的历史记录。普通记录受数量和时间清理规则约束。 | 默认视图中的所有记录 |
| 收藏 | 记录上的独立标记；界面中以不可移除的“收藏”入口展示。收藏记录不受自动清理规则约束。 | 自建分组 |
| 自建分组 | 用户创建的整理容器。一条历史记录最多属于一个自建分组；归入后不受自动清理规则约束。 | 内容类型、默认视图 |
| 内容类型 | 自动识别的文本、图片、视频、文件或链接类型。在默认视图中用于筛选。视频指视频文件。 | 自建分组 |
| 敏感记录 | 识别为从 1Password 桌面应用复制的历史记录。若仍是普通记录，按独立倒计时自动删除。 | 所有密码形态的文本 |
| 最后使用时间 | 最近一次复制到该记录，或从本工具应用该记录的时间；用于排序和普通记录的保留时间计算。 | 首次复制时间 |
| 应用记录 | 将历史记录重新写入系统剪贴板，并在原输入目标可用时直接粘贴。双击和数字快捷键触发同一操作。 | 仅查看记录 |
| 文件副本 | 从原文件复制到本工具数据目录的内容；原文件仍留在原处。 | 移动文件、路径引用 |
| 路径引用 | 只保存原文件路径，不保存文件本体。原文件移动或删除后，引用不能恢复原文件供粘贴。 | 文件副本 |
| 可见序号 | 按当前滚动位置从最上方可见记录开始重新标为 1、2、3……的序号。前九个序号可由数字快捷键应用。 | 记录的固定 ID |
| 固定位置 | 面板按左下角、右下角或下方居中的选项出现；可选择是否记忆拖拽后的位置。 | 跟随光标 |
| 跟随光标 | 每次唤出时面板出现在光标附近；与固定位置互斥，不使用位置记忆开关。 | 固定位置 |

“1 个月”保留时间按固定 30 天计算。同一 1Password 内容再次复制时，敏感记录的倒计时从这次复制重新开始。
