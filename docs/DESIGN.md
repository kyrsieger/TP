# 产品设计

本文收束记录、文件和面板交互的产品规则。术语以[术语表](GLOSSARY.md)为准；平台实现与验证边界见[技术结构](TECHNICAL-ARCHITECTURE.md)。

## 记录模型

- 工具在本机保存用户复制的链接、文字、图片和文件；视频仅指复制的视频文件。数据不做同步，也不加密。
- 每条历史记录有一个自动识别的内容类型：文本、图片、视频、文件或链接。一次复制多个文件只形成一条记录，再次应用时恢复整个文件组合。视频文件与其他文件混合复制时，整条记录归为“文件”。
- **默认视图**展示全部历史记录，不表示记录的数据归属。**普通记录**仅指既未收藏、也未归入自建分组的记录。
- **收藏**是记录上的独立标记，在分组区域以不可移除的“收藏”入口展示。用户可以创建自建分组；一条记录最多属于一个自建分组，同时可以被收藏。

## 去重、排序与清理

- 相同内容不重复创建记录。再次复制已存在的内容，只更新其最后使用时间，使它回到默认视图顶部；原收藏标记和自建分组归属不变。从面板应用记录也更新最后使用时间。所有视图按最后使用时间从近到远排序。
- 文件组合比较每个原路径、文件大小和修改时间；同一路径文件的大小或修改时间变化时创建新记录。文本、链接与图片按保存的内容去重。
- 普通记录受数量和时间两项自动清理规则约束：数量由用户输入，最多 500 条、默认 300 条；时间可选 24 小时、3 天、5 天、7 天、1 个月（固定 30 天），默认 7 天，从最后使用时间起算。重新复制或应用会重新计时。
- 从 1Password **桌面应用**复制的普通记录另有每条独立的自动删除倒计时，秒数由用户设置、默认 90 秒。复制密码 B 不改变较早复制的密码 A 的到期时刻；再次复制同一内容则从这次复制重新计时。
- 已收藏或属于自建分组的记录不受上述任何自动清理规则约束，只能手动删除。若在敏感记录到期前收藏或移入自建分组，它也不再自动删除。
- 设置中的“清理缓存”由用户手动触发：删除全部普通记录及其在数据目录中的文件，并清理无记录引用的应用附件；保留收藏或自建分组记录及其文件，不触碰原文件、数据库和设置。

## 文件与视频

### 保存方式

- 一次复制一个或多个文件只形成一条历史记录；100 MB 阈值按这次复制的**整组文件总大小**计算。
- 总大小不超过 100 MB：在后台将整组原文件复制到本工具数据目录，使用[文件副本](GLOSSARY.md#术语表)恢复粘贴；原文件不移动。
- 总大小超过 100 MB：不保存文件本体，只保存整组文件的原路径，记录为[路径引用](GLOSSARY.md#术语表)。
- 文件副本不设总容量上限。普通记录仍受数量和时间清理规则约束，已收藏或归入自建分组的记录只可手动删除。
- 文件复制不能阻塞系统复制动作或面板。副本尚未保存完成时，界面应显示处理中；只有成功保存后才能声称记录可脱离原文件使用。复制失败时不能将记录误标为文件副本。

### 展示与再次使用

- 普通文件显示原文件名和原路径。多文件记录应显示这是一组文件，并保留各文件的名称与原路径。
- 视频文件显示首帧缩略图，并叠加播放标识或明确的“视频”标签；预览图不是视频本体。
- 路径引用应在界面中清楚标明。原文件被移动或删除后，引用无法恢复原文件供粘贴，应显示不可用状态。
- 应用文件记录时，将整组文件作为文件写回系统剪贴板；文件副本使用数据目录中的副本，路径引用使用原路径。

### 删除与存储

- 删除记录时，同步删除本工具持有的图片、文件副本和缩略图；不删除用户的原文件。
- 视频首帧缩略图可保存在数据目录。即使记录为路径引用，也不能把预览图当作已保存的视频本体。

## 面板与唤出

- 工具以可拖拽调整大小的小面板呈现，默认出现在屏幕右下角，并记忆上次的面板大小。
- 位置模式分为互斥的**固定位置**和**跟随光标**。固定位置提供左下角、右下角、下方居中三个选项；跟随光标每次在光标附近出现。
- 位置记忆开关仅对固定位置模式生效：关闭时每次回到所选固定位置，开启时使用上次拖拽后的位置。
- 唤出快捷键没有默认值，用户需要自行设置。首次配置的入口拟放在 Windows 系统托盘或 macOS 菜单栏；这项入口设计尚未经过界面验收。

## 列表、搜索与筛选

- 分组区域显示“默认”“收藏”和用户创建的自建分组。记录卡片提供收藏按钮，并在旁边提供移动到自建分组的操作。
- 搜索框只检索当前视图：在默认视图搜索全部历史记录，在收藏或自建分组中搜索各自展示的记录。
- 内容类型筛选只出现在默认视图，选项为全部、文本、图片、视频、文件和链接。
- 可见序号按当前滚动位置，从最上方可见记录重新标为 1、2、3……。例如第二条滚到最上方时显示 1；序号不是记录的固定 ID。

## 操作与快捷键

| 操作 | 行为 |
| --- | --- |
| 双击记录 | 应用该记录 |
| `Alt+1` 至 `Alt+9`（Windows）／`Option+1` 至 `Option+9`（macOS） | 应用当前可见序号 1 至 9 对应的记录；不为第 10 条设置数字快捷键 |
| `Tab` | 在“默认”“收藏”和自建分组之间循环切换 |
| `←`、`→` | 在分组之间循环切换 |
| `↑`、`↓` | 在当前列表的历史记录之间移动 |
| `Shift+Esc` | 将焦点移到搜索框 |

数字快捷键只作用于已打开面板中的可见记录，与用户自行设置的全局唤出快捷键不同。

## 应用记录

应用记录时，先将内容重新写入系统剪贴板；若唤出前的目标仍是可用输入框，随后直接粘贴到该输入框。若无法完成跨应用粘贴，内容仍已回到系统剪贴板，界面应如实反馈。成功应用后，该记录的最后使用时间更新并回到默认视图顶部，收藏标记和自建分组归属保持不变。
