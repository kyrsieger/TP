# 产品设计

本文收束记录、文件和面板交互的产品规则。术语以[术语表](GLOSSARY.md)为准；系统组成、实现与验证边界见[系统架构](SYSTEM-ARCHITECTURE.md)。

## 记录模型

- 工具在本机保存用户复制的链接、文字、图片和文件；视频仅指复制的视频文件。数据不做同步，也不加密。
- 每条历史记录有一个自动识别的内容类型：文本、图片、视频、文件、链接或颜色。一次复制多个文件只形成一条记录，再次应用时恢复整个文件组合。单独复制受支持格式的图片文件或仅复制这类图片文件组合时归为“图片”，列表展示第一张图片的缩略图；图片与视频混合，或与其他文件混合复制时，整条记录归为“文件”。
- 复制内容去除首尾空白后若完整匹配带 `#` 的 3、4、6 或 8 位十六进制色值，归为“颜色”；保留原始文本供搜索、去重与再次应用。已有的同格式文本记录也归入“颜色”。
- 新记录保存独立的创建时间；再次复制或应用同一记录只更新最后使用时间，不改变创建时间。升级前的旧记录不补填无法核实的创建时间。
- **默认视图**展示全部历史记录，不表示记录的数据归属。**普通记录**仅指既未收藏、也未归入自建分组的记录。
- **收藏标记**是记录上的独立标记，在分组区域以不可移除的“收藏”入口展示。用户可以创建自建分组；一条记录最多属于一个自建分组，同时可以被收藏。

## 去重、排序与清理

- 相同内容不重复创建记录。再次复制已存在的内容，只更新其最后使用时间，使它回到默认视图未置顶记录的顶部；原收藏标记和自建分组归属不变。从面板应用记录也更新最后使用时间。所有视图先显示置顶记录，多个置顶记录按置顶时间从近到远排序；其余记录按最后使用时间从近到远排序。取消置顶不修改最后使用时间，记录恢复到该时间对应的位置。置顶本身不改变自动清理规则。
- 文件组合（包括从文件夹复制的图片）比较每个原路径、文件大小和修改时间；同一路径文件的大小或修改时间变化时创建新记录。文本、链接与直接复制的图片按保存的内容去重。
- 普通记录受数量和时间两项自动清理规则约束：数量由用户输入，最多 500 条、默认 300 条；时间可选 24 小时、3 天、5 天、7 天、1 个月（固定 30 天），默认 7 天，从最后使用时间起算。重新复制或应用会重新计时。
- 设置中“普通记录数量上限”标签后以浅色文字显示“当前普通记录数/已生效数量上限”，例如 `199/300`。数量不包含收藏或自建分组记录，不受搜索、类型筛选或当前视图影响，随记录变化更新；输入尚未提交或等待清理确认时仍显示已生效的上限。
- 修改数量上限或保留时间时，若新设置会删除已有普通记录，先在面板内弹出确认窗口，沿用设置页的字体、圆角、浅色边框和按钮风格，“删除并应用”按钮沿用“清理缓存”的红色。窗口告知将删除的记录条数、对应本地文件也会删除及操作无法撤销；收藏和自建分组记录保留。仅在确认后保存新设置并执行清理，取消、按 Esc 或隐藏面板则保留原设置，设置控件恢复原值。不产生删除时直接保存。等待确认期间仍按原设置运行；确认后若待删除条数增加，重新显示最新条数并要求确认。
- 从 1Password **桌面应用**复制的普通记录另有每条独立的自动删除倒计时，秒数由用户设置、默认 90 秒。复制密码 B 不改变较早复制的密码 A 的到期时刻；再次复制同一内容则从这次复制重新计时。
- 已收藏或属于自建分组的记录不受上述任何自动清理规则约束，只能手动删除。若在敏感记录到期前收藏或移入自建分组，它也不再自动删除。
- 设置中的“清理缓存”由用户手动触发：删除全部普通记录及其在数据目录中的文件，并清理无记录引用的应用附件；保留收藏或自建分组记录及其文件，不触碰原文件、数据库和设置。清理区块位于设置页下方、版本号上方，左侧为标题和与设置项标签同色的说明，右侧为红色清理按钮；说明显示当前可清理缓存大小（按本次清理会删除的应用附件字节数计算，不包含原文件和数据库）并提示操作无法撤销。点击按钮后需再次确认。

## 文件与视频

### 保存方式

- 100 MB 阈值按一次复制的**整组文件总大小**计算。
- 总大小不超过 100 MB：在后台将整组原文件复制到本工具数据目录，使用[文件副本](GLOSSARY.md#术语表)恢复粘贴；原文件不移动。
- 总大小超过 100 MB：不保存文件本体，只保存整组文件的原路径，记录为[路径引用](GLOSSARY.md#术语表)。
- 文件副本不设总容量上限。
- 文件复制不能阻塞系统复制动作或面板。副本尚未保存完成时，界面应显示处理中；只有成功保存后才能声称记录可脱离原文件使用。复制失败时不能将记录误标为文件副本。

### 展示与再次使用

- 普通文件在记录行显示原文件名，并在文件名左侧以紫色标签显示文件后缀（不含点、使用大写）；目录显示“目录”，即使目录名带后缀也不按文件后缀显示。多文件记录显示文件数量和各名称，标签一致时显示该标签，不一致时显示“多格式”。无后缀的普通文件显示“文件”。原路径保留在记录数据中供再次应用，不在列表中展示。
- 视频文件在列表显示首帧缩略图并叠加播放标识；一条记录包含多个视频文件时使用第一个文件的首帧。列表不显示视频文件名、类型文字或类型图标。首帧预览图不是视频本体，不播放视频；无法生成首帧时，列表显示不可用提示。
- 原文件被移动或删除后，路径引用无法恢复原文件供粘贴，应显示不可用状态。
- 应用文件记录时，将整组文件作为文件写回系统剪贴板；从文件夹复制的图片记录也保持文件粘贴方式。文件副本使用数据目录中的副本，路径引用使用原路径。
- 应用直接复制（如截图）的图片记录时，同时写回图片数据、本工具保存的图片文件和该文件的纯文本路径：图片数据供聊天框等按图片粘贴，文件和纯文本供终端、编辑器等按路径粘贴。文件使用数据目录中的原图副本。

### 删除

- 删除记录时，同步删除本工具持有的图片、文件副本和缩略图；不删除用户的原文件。

## 面板与唤出

- 工具以可拖拽调整大小的小面板呈现，默认出现在屏幕右下角，并记忆上次的面板大小。
- 面板默认宽 420、高 600；缩放光标出现在窗口边框或内侧拖拽区时，双击左右边缘只恢复默认宽度，双击上下边缘只恢复默认高度，双击角落恢复两维。恢复后的大小同样会被记忆。
- 记录列表的滚动条应能直接拖动，不能与面板右侧的缩放拖拽区重叠。
- 位置模式分为互斥的**固定位置**和**跟随光标**。固定位置提供左下角、右下角、下方居中三个选项；跟随光标每次在光标附近出现。
- “记忆拖拽位置”开关仅对固定位置模式生效：关闭时每次回到所选固定位置；开启时保持面板当前位置并从该位置开始记忆，之后使用拖拽后的位置。
- 窗口标题为 TP。面板使用自绘标题栏，显示 TP 标识和最小化、最大化或还原、关闭按钮；标题栏空白处可拖动窗口，关闭按钮隐藏面板。标题栏下方的单行工具栏依次放置搜索框、内容类型筛选、置顶开关和设置按钮；横向分组标签位于工具栏下一行。面板不显示底部操作提示。
- 面板、悬停预览和大图预览的窗口圆角、边框和阴影由操作系统绘制（Windows 11 为约 8 像素圆角、1 像素边框与窗口阴影），半径由系统决定、应用不能配置；贴合窗口边缘的容器沿用同一半径，页面不在窗口边缘另画圆角或边框。
- 工具栏按钮使用相同的扁平图标风格；输入框聚焦时以高亮边框提示，不显示外围焦点环。置顶默认关闭并记忆用户选择；开启后面板保持显示在其他普通窗口前面，应用记录时不自动隐藏面板。用户仍可主动隐藏面板，重新唤出后继续保持置顶。
- 唤出快捷键没有默认值，用户可在设置中配置；通过快捷键唤出面板时关闭设置覆盖层，显示记录列表，保留此前的分组，并按“保留搜索框输入”设置恢复搜索词。左键单击 Windows 系统托盘或 macOS 菜单栏图标也可唤出面板；右键图标可通过“打开剪贴板”菜单项打开面板。
- TP 启动后静默常驻，不主动显示面板：无论手动启动还是登录启动，都只显示 Windows 系统托盘或 macOS 菜单栏图标，不创建面板和预览窗口，剪贴板记录与自动清理继续运行。由用户通过唤出快捷键或托盘图标首次创建面板，页面就绪并加载最新记录后显示。
- 每次唤起面板并完成显示后，将键盘焦点交给当前列表已选中的首条记录，可直接按 F2 或自定义重命名快捷键操作，无需先点击记录。恢复搜索词时选中并聚焦搜索结果中的首条记录；空列表不聚焦记录。之后用户主动聚焦搜索框、分组或设置时，继续使用各自的按键规则。
- 隐藏面板时清空列表及图片，并停止后台列表刷新；保留当前分组与内容类型筛选，搜索词按“保留搜索框输入”设置处理，下一次唤出时恢复这些状态并读取最新记录。面板闲置 30 秒后销毁，同时释放仍隐藏的预览窗口，再次唤出时重新创建；重复隐藏不延长闲置时间。上述浏览状态只在本次 TP 运行期间保留，退出应用后不保存。Windows 隐藏窗口同时进入尽力回收的低内存模式，显示前恢复正常模式；内存下降幅度不作固定保证。
- 设置中的“保留搜索框输入”默认开启，旧配置缺少此项时也视为开启；关闭后，每次面板隐藏都清空搜索框内的关键词，包括标题栏关闭、Esc 隐藏和应用记录后自动隐藏，再次唤出或窗口销毁后重建均从空搜索框开始。切换开关立即保存，关闭开关时不清空仍显示的面板中的搜索词；仅关闭设置或预览、最小化窗口，或置顶时应用记录而未隐藏面板，均不触发清空。Esc 在搜索词非空时仍先清空搜索词并保持面板显示。
- “开机启动”首次安装默认关闭；开启后，登录系统时 TP 按上述静默方式启动。开关变更后立即生效，并保存在本地数据库。保留应用数据卸载重装后，首次运行 TP 时恢复已保存的选择并更新系统启动项的安装路径。旧版本首次迁移接收当前系统启动状态；如果旧版启动项已经被删除，无法推断之前的选择，需要重新开启一次。
- Windows 设置提供“在任务栏显示图标”开关，默认开启，旧配置缺少此项时也视为开启。开启时主面板显示或最小化后在任务栏中显示 TP 图标；关闭后主面板不显示任务栏图标，仍可通过系统托盘或唤出快捷键打开。变更立即生效并保存，重启应用或面板闲置释放后重建均恢复已保存的选择。静默启动和隐藏面板时不显示任务栏图标，两个预览窗口始终不显示任务栏图标。此开关仅在 Windows 提供，macOS 菜单栏及 Dock 行为沿用原实现。
- 设置以覆盖层显示在工具栏下方，沿用首页的字体、间距、扁平控件和高亮样式；普通记录保留时间和固定位置使用相同风格的页内下拉菜单。设置页没有保存按钮；快捷键、选项和开关在变更后立即保存。普通记录数量上限在按 `Enter` 或输入框失去焦点时提交，输入或点击数字增减按钮期间不保存、不触发删除提醒；1Password 记录保留秒数在停止输入后短暂延迟保存。数量或保留时间的变更会删除已有记录时，先按清理规则等待用户确认。无效数字不会保存，保存失败时恢复已保存的值并提示错误。快捷键被占用时，输入框仍显示用户刚按下的组合键，设置项下持续显示红色提示，但不将其保存为生效快捷键；解除占用后可重试。输入框中的 `Control` 修饰键显示为 `Ctrl`。设置页底部用表格列出当前生效的唤出快捷键及面板内的键盘操作。按 `Esc` 或再次点击设置按钮离开设置时，焦点回到进入设置前选中的对象，该对象已不存在时回到搜索框；原本没有选中对象时移走焦点，避免设置按钮残留焦点环。
- 面板不显示“隐藏”按钮；按 `Esc` 可隐藏面板，搜索词非空时首次按 `Esc` 只清空搜索词、面板保持显示，搜索框为空时才隐藏。Windows 面板不响应 WebView 自带的打印、查找、刷新和缩放等浏览器快捷键。
- 设置页顶部依次显示“开机启动”、“在任务栏显示图标”（仅 Windows）、“保留搜索框输入”、“唤出快捷键”及“记录重命名快捷键”；各开关的说明紧跟对应开关。
- 设置页最底部在“清理缓存”区块下方以浅色小字居中显示“当前版本：版本号”，版本号读取运行中应用的版本信息。

## 列表、搜索与筛选

- 未命名且无搜索词时，文本和链接记录在列表中以正文首行作为行内容，不单设标题；首行之后还有非空白内容时，在首行末尾以空格加省略标记 `...`，提示这条记录没有完整显示；只有行列宽度造成的截断由单行省略号表现，不加此标记。正文使用常规字重。普通文件仍显示文件名。图片和视频记录在列表中不显示文件名、类型文字或类型图标。
- 所有类型的记录均可重命名，可通过记录右键上下文菜单的第一项“重命名”或记录重命名快捷键进入，不提供右侧重命名按钮。快捷键默认 F2，可在设置中按键自定义，支持 F1 至 F24（可带修饰键）及带修饰键的字母、数字；不能与已有列表操作或全局唤出快捷键重复。按 Backspace 或 Delete 可清除快捷键，右键入口始终保留。变更立即保存，重启后恢复；旧配置缺少此项时使用 F2。仅当焦点位于记录列表且有当前记录时作用于当前记录；搜索框、分组区域、菜单、设置、标题编辑和其他文字输入中不触发，长按与输入法组合事件不触发重复编辑。菜单项右侧以浅色文字显示当前生效的快捷键，清除后不显示按键。标题在记录内原地编辑，Enter 保存，Esc、失焦、切换视图或隐藏面板取消；输入法组词期间的 Enter 不提交。标题去除首尾空白，最多 100 个字符，不能换行；空标题保存后恢复未命名样式。重命名只修改记录标题，不改变原文、原文件名、去重摘要、最后使用时间、收藏、置顶、分组或清理规则；再次复制相同内容时保留已有标题。保存失败提示错误并保留编辑内容。右键菜单可用上下方向键选择、Enter 或 Space 执行、Esc 关闭。
- 重命名期间，文字、链接、文件和颜色记录仅显示一个接近整行宽度的输入框，临时隐藏其他元素，编辑行高为 48 像素。图片和视频保留原有缩略图或首帧及播放标记，在画面上方显示标题输入框，编辑行高为 212 像素；隐藏序号、状态标记、搜索叠加片段和操作按钮。输入框高 32 像素，文字及提示均使用常规字重，提示仅为“输入标题”；保留细边框，不叠加焦点环或阴影。保存和取消后恢复正常展示；媒体清空标题或取消未命名记录的编辑后恢复 180 像素行高。
- 已命名的文字、链接、文件和颜色记录保持 48 像素单行：左侧显示较粗的标题，右侧紧跟常规字重的原内容，仅留 8 像素间距；标题按实际长度优先完整显示，不设固定列宽或占比上限。右侧有剩余空间时才显示正文，正文按剩余宽度单行省略；标题本身超过可用内容宽度时才省略标题，此时不显示正文。链接图标、文件后缀/多格式/目录标签、颜色圆形色块位于标题左侧。文字正文继续仅显示首行及原有多行提示，文件继续显示原文件名或整组数量与名称，颜色继续显示原色值。已命名的图片和视频行高 212 像素，上方新增 32 像素标题区，下方保留原 180 像素画面区；标题不覆盖画面，不增加媒体文件名或类型图标。
- 工具栏下方的分组区域使用浅色圆角标签，显示“默认”“收藏”和用户创建的自建分组；文字与选中高亮沿用原有蓝色系。点击“＋”后在末尾直接输入新分组名称；双击自建分组名称可原地重命名，右键自建分组名称可打开包含“重命名”“删除”的菜单。原地输入按 Enter 提交、按 Esc 或失焦取消。删除分组无需再次确认，其中未收藏的记录回到普通记录并按普通记录规则清理，已收藏的记录保留收藏标记；“默认”和“收藏”不能重命名或删除。移动到分组使用与类型筛选一致的页内菜单，包含“未分组”及所有自建分组，以右侧的勾标记当前归属，不附加“当前”文字；蓝色背景及文字只标记鼠标悬停或键盘选择的选项，两种操作共用同一选择位置。选择其他分组时，当前归属的勾保持灰色；选择当前所属分组时，勾随该行高亮。菜单不显示目标箭头或底部操作提示。
- 记录行右侧在悬停时显示圆角矩形按钮组，依次为置顶、收藏、移动到自建分组、删除；组内按钮之间只保留按钮间距。已有分组的记录在按钮组中高亮分组按钮，与置顶和收藏按钮的状态提示一致。未悬停时，已置顶记录在右侧显示置顶图标，已收藏记录显示黄色星号，属于自建分组的记录显示分组图标；标记同时存在时，依次为置顶、收藏、分组。悬停显示按钮组时隐藏这些状态图标。
- 不包含目录的文件、图片和视频记录在记录项任意位置右键，均显示同一页内菜单，依次为“重命名”“复制路径”“打开所在目录”“另存为”。文字、链接、颜色和包含目录的记录仅显示“重命名”。“复制路径”按一行一条复制全部文件路径；“打开所在目录”选中全部文件所在目录；二者优先使用仍存在的原文件，原文件不存在时使用文件副本。文件副本记录的所有副本平铺在同一目录，因此只打开一个窗口即可同时看到整组文件；路径引用记录的原文件可能分布在不同目录，按目录分别打开。直接复制的图片使用数据目录中的图片副本。
- “复制路径”写入的是纯文本路径，属于用户主动复制：粘贴到其他输入框可用，同时与其他复制内容一样按文本记录规则进入历史记录并参与去重与自动清理。
- “另存为”先让用户选择一个目录，再将全部文件副本保存至该目录；没有副本、目标目录已有同名文件或副本不可用时不保存并提示错误。它始终使用文件副本，不使用原文件。文本、链接、颜色和目录记录不显示文件路径操作；记录项不保留浏览器原生右键菜单。
- 分组区域内容超出宽度时，不显示滚动条；鼠标悬浮在分组区域可直接用滚轮左右滚动。通过 Tab 或 Shift+Tab 切换分组时，选中的分组标签自动滚动到可见范围；分组标签不显示焦点环。记录和分组的右键菜单每次打开都不预选任何菜单项，不保留上次选择，也不显示外围焦点环；鼠标悬停或按方向键后才高亮对应项。未选择菜单项时 Enter 或 Space 不执行操作；首次按 ↓ 选择第一项，首次按 ↑ 选择最后一项，后续循环选择。键盘聚焦的菜单项使用与鼠标悬停相同的浅色行背景。
- 根据当前列表高度及记录实际行高，计算从顶部能完整容纳的 n 条记录；当第 n+10 条记录进入可见范围后，当前分组标签的名称换成“返回顶部”图标，按钮宽度保持不变。点击图标后列表以快速、起步略有加速的可见动画滚回顶部；滚回阈值以上时恢复分组名称。面板大小或列表内容变化时重新计算，用户主动滚动可中断动画。
- 搜索同时检索记录标题、正文和原路径。搜索框只检索当前视图：在默认视图搜索全部历史记录，在收藏或自建分组中搜索各自展示的记录。按 `Ctrl+F` 或点击搜索框聚焦后，输入内容并立即搜索；未聚焦时，普通字符、输入法和退格键不会自动聚焦搜索框或修改搜索词。按 Tab、Shift+Tab 切换分组或按 ↑、↓ 导航记录时，搜索框失去焦点；←、→ 在搜索框内保留文本光标移动，不触发分组切换和预览。搜索框聚焦时，退格与向前删除按键（包括带 Ctrl 的组合）保留文字编辑行为，不删除记录；未聚焦时，Windows 用 `Ctrl+Backspace` 或 `Delete` 删除选中记录，macOS 用 `Ctrl+Delete`（主键盘退格键）删除选中记录。搜索框不显示浏览器保存的输入历史；有搜索词时显示清空按钮，点击后清除搜索词、恢复当前视图的完整列表并把焦点留在搜索框。搜索词非空时按 `Esc` 同样清除搜索词并恢复完整列表，但随后移走搜索框焦点，面板不隐藏；搜索框为空时按 `Esc` 才隐藏面板。
- 搜索结果在列表中显示包含关键词的文字片段，命中处以主色为背景、白色文字高亮；关键词位于正文首行或文件名之外时，显示正文或原始路径中的命中片段。图片和视频仅在原文或路径命中时叠加显示命中片段，只有标题命中时保留画面与标题，不叠加无关文件名。悬停预览中的正文和原始路径同样高亮关键词；长文本自动滚动到首个命中处。
- 内容类型筛选仅在默认视图可用，点击工具栏图标后以下拉菜单选择全部、文本、图片、视频、文件、链接或颜色；切换到其他分组时按钮保留在原位并浅色化、不可点击。筛选生效时，图标换为所选类型图标并高亮；紧邻右侧的清除按钮与类型图标共用一个加宽控件。颜色记录显示色值和色块。
- 记录以扁平单行展示，普通行高 48 像素，悬停时不展开；相邻记录之间显示从正文起始位置延伸到右侧的极浅 1 像素分割线，选中记录上下两侧的分割线隐藏，末条记录下方不显示；不在列表中显示路径和时间。未命名图片和视频行高 180 像素，已命名时为 212 像素，缩略图在行内居中，上下保留约 10 像素，左右为序号和操作区留空。常见比例的图片完整等比显示；宽高比不大于 1:2.5 的竖向长图截取偏上方的正方形区域，宽高比不小于 3:1 的横向长图截取居中的 9:4 区域。视频使用相同规则处理首帧。列表只创建可见范围及上下各约 180 像素内的记录行并加载其缩略图，离开该范围的记录行及图片释放；滚动范围、键盘选择和可见序号仍按完整筛选结果计算。颜色记录的色块为圆形。影响可用性的保存中、保存失败和文件不可用状态应显示；保存方式不显示状态文字。列表保留可直接拖动的滚动条。
- 分组、置顶等操作使列表重排时，仍在创建范围内的已加载图片与视频缩略图保持显示，不因列表刷新重新读取。
- 鼠标停在记录上 300 毫秒后，或在面板中按 `→`，在面板外显示预览窗。优先放在右侧；右侧放不下完整宽度时尝试左侧；两侧都放不下时缩窄预览窗，仍无法容纳时允许覆盖面板的一部分。预览窗与主面板的水平间距约 2 像素。预览窗约 420 像素宽，高度随内容变化，超出屏幕可用高度时在窗内滚动；位置与尺寸始终限制在当前屏幕可用区域内。鼠标可移入预览窗阅读或滚动；离开记录和预览窗、鼠标悬停到其他记录、滚动列表、切换分组或隐藏面板时关闭预览。键盘触发的预览立即出现，不等待 300 毫秒，并在选中记录变化时关闭；选中记录不在列表可视范围时，先把它滚入可见范围再显示。预览不改变剪贴板或最后使用时间。
- 两个预览窗口首次使用时创建；关闭时立即清空内容并隐藏，闲置 30 秒后销毁，再次使用时重新创建。启动时不创建预览窗口。
- 悬停预览不显示记录类型和时间；记录属于自建分组时展示分组字段，未分组时省略。已命名记录在正文上方显示记录标题，未命名记录不显示标题；正文之下依次为分组等字段和原始路径；图片和视频的正文是画面，文本与链接的正文是完整原文，颜色的正文是由色值填充的实心圆及色值，文件的正文是整组文件的原始路径。原始路径中的文件名以加粗区分。文本记录的原文区域最大高度为 320 像素，超出时仅在原文区域内滚动，预览窗仍限制在屏幕可用高度内。图片显示由本工具保存的原图生成的完整预览图，最长边不超过 1440 像素，保持比例、不裁剪、不放大；原图保留供大图预览和写回剪贴板使用；视频显示最长边不超过 1280 像素的完整首帧与原始路径，不播放视频。仅含单个文件的记录中，Markdown、JSON、TXT 及常见代码等文本文件在其路径下显示原始文本内容，内容区域最高 320 像素，可独立滚动；仅读取不超过 1 MB 的 UTF-8 或带 BOM 的 UTF-16 文本。多文件记录不读取任何文件的内容。PDF、Office 等二进制文件和目录不读取内部内容。多文件的原始路径使用同一个背景，以无序列表标记分隔。直接复制的图片没有原文件，路径位置显示本工具保存的图片副本路径（与“复制路径”和应用记录写回的路径一致）。悬停预览不显示正常的“保存副本中”状态；仅在“文件已不可用”或“副本保存失败”时，在全部字段与原始路径之后、以黄色文字显示一行提示，不显示“状态”字段名。
- 单文件悬停预览的路径前不显示列表圆点；多文件保留无序列表标记。
- 纯图片或纯视频文件组合在悬停预览和大图预览中按复制顺序逐项显示，每张图片或每个视频首帧占一页；图片与视频混合的组合仍归为文件，不提供画面预览。多页时悬停预览的画面区域保持固定高度，大图预览在浏览同组文件期间保持固定窗口尺寸；图片在画面区域内居中完整显示，按需等比缩小、不裁剪、不放大小图，较矮图片的上下留白。相邻页先载入，切换时当前画面向左或右移出，下一画面从对应方向紧接着移入；加载期间保留当前画面。小巧、浅色的半透明圆角指示器在悬停预览中固定于画框底部，仅当鼠标悬停在画框上时显示；在大图预览中覆盖画面下缘。每页对应一项，当前项为较长的横向圆角矩形，不使用粘黏效果；极窄图片允许指示器超出图片宽度但仍置于画面区域内。点击指示器跳到对应页，在画面区域滚动鼠标滚轮切换相邻页，到首尾停止；单页不显示指示器。旧记录也可按需生成后续页面；某页不可预览时保留其位置并显示不可用提示。
- 选中图片或视频记录后按 `Space` 或 `←` 打开独立的大图预览窗，显示完整画面、不裁剪；图片读取保存的原图，视频读取最长边不超过 1280 像素的首帧。单页时窗口按画面实际尺寸自适应，小图不放大，窗口边缘贴合画面；多页时窗口固定为当前屏幕可用区域的 90%、宽 1600 像素和高 1000 像素三者允许的最大范围，切换期间不改变窗口尺寸与位置。窗口初次打开时在当前屏幕可用区域内居中，可按住画面拖动；图片右上角的关闭按钮使用带浅色描边的深色圆形背景，以便在明暗图片上识别。再次按 `Space`、按 `Esc` 或点击关闭按钮时关闭，并将焦点还给面板，保留原选中记录。关闭大图预览的 `Esc` 不隐藏面板；输入控件有焦点时 `Space` 保持正常输入。大图预览期间不显示悬停预览；两种预览都不改变剪贴板或最后使用时间。
- 可见序号按当前滚动位置，从最上方可见记录重新标为 1 至 9；第 10 条及之后不显示序号。例如第二条滚到最上方时显示 1；序号不是记录的固定 ID。
- 搜索、类型筛选、切换分组或记录刷新后，若大图预览中的记录不再属于当前筛选结果，立即关闭大图预览；记录仍在结果中时保留大图。关闭后可以继续打开其他记录的悬停预览或大图预览。

## 操作与快捷键

| 操作 | 行为 |
| --- | --- |
| 双击记录 | 应用该记录 |
| 用户设置的唤出快捷键 | 从其他应用唤出面板；默认未设置 |
| `F2`（可在设置中自定义） | 仅当焦点位于记录列表时重命名当前记录；输入框、分组、菜单和设置中不触发 |
| `1` 至 `9`（Windows 和 macOS） | 搜索框未聚焦时，单独按数字键（含数字小键盘）立即应用当前可见序号 1 至 9 对应的记录；长按不重复应用，不为第 10 条设置数字快捷键 |
| `Ctrl+1` 至 `Ctrl+9`（Windows 和 macOS） | 无论搜索框是否聚焦、是否有关键词，都立即应用当前可见序号 1 至 9 对应的记录（含数字小键盘）；组合键本身不修改搜索词；长按不重复应用，不为第 10 条设置数字快捷键 |
| Windows：`Ctrl+Backspace` 或 `Delete`；macOS：`Ctrl+Delete`（主键盘退格键） | 搜索框未聚焦时删除所有选中记录；长按不重复删除 |
| `Ctrl+D`（Windows 和 macOS） | 收藏或取消收藏所有选中记录 |
| `Ctrl+F`（Windows 和 macOS） | 将焦点移到搜索框 |
| `Ctrl+G` | 打开分组菜单，将所有选中记录移到所选分组；用上下方向键选择，按 `Space` 或 `Enter` 确认 |
| `Ctrl+P` | 置顶或取消置顶所有选中记录 |
| `Ctrl+A` | 主面板输入框聚焦时全选框内文字，包括搜索、记录标题、设置数字和分组名称；主面板其他区域、悬停预览和大图预览中不执行全选 |
| `Tab`、`Shift+Tab` | 在“默认”“收藏”和自建分组之间循环切换 |
| `←` | 选中图片或视频记录时打开大图预览，与 `Space` 相同；其他类型记录无响应 |
| `→` | 为当前选中记录立即显示悬浮预览，不等待鼠标悬停的 300 毫秒 |
| `↑`、`↓` | 在当前列表的历史记录之间循环移动：第一条按 `↑` 跳到最后一条，最后一条按 `↓` 回到第一条 |
| `Shift+↑`、`Shift+↓`；`Shift+点击记录` | 以最近一次单选记录为起点，按当前列表顺序扩展或收缩连续选择范围；方向键到首尾停止 |
| `Space` | 选中图片或视频记录时打开大图预览；预览窗中再次按下则关闭 |
| `Enter` | 应用当前选中记录；分组或记录菜单中确认选项；编辑记录标题、分组名或普通记录数量上限时提交 |
| `Esc` | 关闭当前菜单、设置或大图预览；搜索词非空时清除搜索词、移走搜索框焦点并保留面板，搜索框为空时在主页隐藏面板；编辑记录标题或分组名时取消 |

两种数字快捷键同时保留，只作用于已打开面板中的可见记录，与用户自行设置的全局唤出快捷键不同。搜索框聚焦时，单独按数字键仍输入搜索词；设置界面、清理确认弹窗及其他输入控件中不应用数字快捷键。记录标题编辑期间保留原生文字编辑行为，数字应用、收藏、分组、置顶、搜索和导航快捷键均不触发。两种方式均忽略输入法组合事件以及 Alt、Shift、Command / Windows 键和 AltGraph 组合。应用记录后，搜索词是否保留仍遵循“保留搜索框输入”设置。
macOS 的 `Ctrl` 指 Control（⌃）。主键盘的 `Delete` 是退格键，与 Windows 的 `Backspace` 对应；`Fn+Delete` 或独立的向前删除键不触发记录删除。设置中的快捷键表按当前平台显示按键名称。
面板打开或切换分组时，列表回到顶部并默认选中当前视图中的第一条记录；空列表不选中记录。
普通点击或不带 Shift 的上下方向键恢复单选。批量收藏或置顶时，只要有一条尚未启用，就为所有选中记录启用；全部已启用时，才为所有选中记录关闭。筛选或列表刷新后，只保留当前列表中仍存在的选中记录；`Enter`、`Space` 和 `←`、`→` 仍作用于当前焦点记录。

## 应用记录

应用记录时，先将内容重新写入系统剪贴板；若唤出前的目标仍是可用输入框，随后直接粘贴到该输入框。写回成功后不显示底部提示，无论是否完成跨应用粘贴；若无法完成跨应用粘贴，内容仍保留在系统剪贴板供手动粘贴。写回失败等操作错误仍显示底部错误提示。
