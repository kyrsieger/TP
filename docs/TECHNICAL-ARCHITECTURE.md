# 技术结构

## 目标与状态

- 目标平台：Windows 11 与 macOS；数据只保存在本机，不做同步。
- 当前实现采用 Tauri 2、TypeScript 界面、Rust 系统层、SQLite 本地数据库。
- Windows 编译检查已作为第一步；各系统能力仍需实际操作验证。
- macOS 平台代码必须实现。当前开发机器只有 Windows，因此现阶段只验证 Windows 运行行为；macOS 编译和运行验证在具备 Mac 环境后补做。

## 模块边界

1. **系统适配层**：监听系统剪贴板变化，读取和写回文本、图片、文件组合；识别复制来源；注册用户设置的唤出快捷键；控制面板窗口；尝试向原应用粘贴。
2. **记录服务**：识别[内容类型](GLOSSARY.md#术语表)、计算去重标识、写入创建时间并维护最后使用时间和记录置顶时间、处理收藏和自建分组、执行普通记录及敏感记录的清理规则。置顶时间用于列表排序，不参与自动清理判断。
3. **本地存储**：SQLite 存储记录、可为空的置顶时间与创建时间、分组、设置和文件元数据；已有数据库启动时补充缺少的字段，旧记录的创建时间保持为空。应用数据目录为图片保存原图与列表缩略图，为视频保存最长边不超过 1280 像素的首帧与列表缩略图，并保存符合条件的[文件副本](GLOSSARY.md#术语表)。旧记录缺少新缩略图时按需生成；旧视频源已不可用时沿用已有的低分辨率首帧。
4. **面板界面**：自绘标题栏与窗口控件、展示与筛选记录、当前分组搜索、收藏与移动分组、键盘导航、位置、大小与置顶设置。窗口使用无系统装饰的 Tauri 窗口；设置仍作为覆盖层显示。悬停预览与 `Space` 大图预览各使用一个隐藏启动的无装饰窗口；面板根据当前屏幕可用区域定位预览窗，大图窗口根据图片尺寸在原有上限内贴合画面，支持按住画面拖动，并在面板隐藏时同步隐藏预览窗。列表按可见区域加载缩略图；图片悬停及大图预览按需读取原图，视频两种预览读取首帧。

系统适配层按 Windows 和 macOS 分开处理目标窗口与粘贴键，剪贴板监听与内容读写使用支持两平台的 `clipboard-rs`。两者只提供变化线索，历史记录始终由本工具自行维护。工具主动写回剪贴板时，记录服务识别这次写入，避免产生额外历史记录；被应用的原记录只更新最后使用时间。

文件规则已经确定：混合文件组合标记为“文件”；文件组合去重比较每个路径、大小与修改时间。视频首帧预览暂依赖 `PATH` 中的 `ffmpeg`，缺少时记录仍可使用但无缩略图；这个运行依赖需要在平台验收中处理。

## 优先验证的系统能力

| 能力 | Windows 11 当前验证 | macOS 代码与后续验证 |
| --- | --- | --- |
| 后台监听文字、图片和文件组合 | 原型和实际测试 | 实现适配代码；有 Mac 后运行测试 |
| 识别 1Password 桌面应用为复制来源 | 原型和实际测试 | 实现适配代码；有 Mac 后运行测试 |
| 将文件组合写回系统剪贴板 | 原型和实际测试 | 实现适配代码；有 Mac 后运行测试 |
| 唤出前的输入目标、自动粘贴 | 原型和实际测试 | 实现适配代码；验证系统所需权限和实际效果 |
| 可配置全局唤出快捷键及小面板定位 | 原型和实际测试 | 实现适配代码；有 Mac 后运行测试 |
| 面板边缘拖动及双击恢复默认宽高 | 内侧拖拽区双击已运行验证；原生边框双击待手动验证 | Windows 拦截原生边框双击消息；macOS 监听窗口边框双击，内侧拖动使用指针事件；有 Mac 后运行测试 |
| 面板置顶及重启后恢复 | Windows 11 运行验证 | 使用 Tauri 窗口接口；有 Mac 后运行测试 |
| 登录后后台启动 | 待 Windows 11 运行验证 | Tauri autostart 插件在 Windows 和 macOS 注册登录启动；启动参数控制面板隐藏；有 Mac 后运行测试 |

来源识别和跨应用自动粘贴是主要技术风险。原型需要验证真实的 1Password 桌面应用复制流程，以及输入框、文件管理器等目标应用。若平台权限或目标应用阻止自动粘贴，记录仍应写回系统剪贴板；界面需给出明确结果，不能声称已经粘贴成功。

## 实施顺序与完成条件

1. 系统能力原型 → Windows 11 上能捕获并恢复文字、图片、单文件与多文件，识别 1Password 桌面应用，并验证自动粘贴；同时写出 macOS 对应适配代码。
2. 本地记录与文件存储 → 验证去重、排序、文件副本与路径引用、清理规则及删除记录后的副本清理。
3. 面板与设置 → 验证位置、大小、分组、收藏、搜索、筛选和全部指定快捷键。
4. 平台验收 → 当前完成 Windows 11 运行验证；取得 Mac 环境后补做 macOS 编译、权限与运行验证。
