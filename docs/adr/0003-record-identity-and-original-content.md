# 以复制内容确定记录身份，展示与整理不改变身份

一次复制只建立一条记录，同次复制的文件组合整体保存，不把剪贴板的多种表示分别建档。去重身份包含内容类型，文本使用原文字节、直接图片使用保存的 PNG 字节，文件组合使用原顺序中的原路径、大小和修改时间，在识别文件变化与避免读取全部文件内容之间取舍。记录标题、收藏、自建分组和置顶独立于去重身份，重复复制保留这些属性与创建时间，避免整理结果被重复复制抹掉。

## 后果

同一组文件按不同顺序复制会产生不同记录，相同内容放在不同路径也不会合并；反过来，同一路径的内容若改变但大小和修改时间不变，则不能识别为新内容。目录只比较自身元数据，不递归比较内部文件，因此不能用历史去重结果证明文件或目录内容完全相同。
