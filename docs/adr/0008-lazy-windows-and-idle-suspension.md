# 保留主窗口，闲置时释放面板内容

GPUI 版静默启动时创建隐藏的主窗口，首次唤出时才加载历史记录。Windows 11 实测中，释放面板内容降低了图片混合历史的内存占用，开启旧「后台常驻」设置未带来稳定的唤出速度优势。因此移除该设置，面板持续隐藏约 30 秒后自动释放浏览内容，保留主窗口，剪贴板采集与唤出入口继续运行。

## Tauri 版原始决策

TP 静默启动时只运行宿主后台能力，不预建 WebView；Windows 既有测量表明，主面板销毁后重建运行环境有明显唤出成本，因此默认保留隐藏内容一分钟，再清空列表、图片和快照并尝试挂起，保留主窗口供恢复。小预览 WebView 按需创建、隐藏闲置后销毁；大图预览改由原生窗口管理，见 [ADR 0011](0011-native-large-preview.md)。用户可开启“后台常驻”持续保留主面板内容，以更多内存换取更快唤出。挂起使用系统公开能力，不受支持或失败时保留清空后的隐藏面板，不保证固定内存降幅或恢复耗时；现有运行证据来自 Windows，macOS 分支尚未编译或实机运行。
