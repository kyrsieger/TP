# 由 Rust 宿主持有后台工作和数据，页面只负责交互

> 2026-11-06：实现已替换为 GPUI。下文记述原技术选型；后台采集、清理和持久化归 Rust 管理的边界仍成立，当前由 tp-core、tp-desktop、tp-gpui 承担，不再存在 React 页面或 Tauri 命令桥。


TP 在面板不存在或挂起时仍须采集剪贴板、清理记录并响应托盘和快捷键，因此使用 Tauri 2 将这些职责及持久化放在 Rust 宿主中，React 与 TypeScript 页面只通过命令和事件参与交互。主面板与两个预览窗口共享同一宿主状态，页面不直接访问数据库或任意文件，也不另设业务服务。这个边界让页面可以按需创建和释放，而不使历史保存依赖页面存活。
