# 应用标识和数据目录统一为 TP

应用标识从 `com.tp.clipboard` 改为 `TP`。这是本项目选择的本地应用身份，不代表域名所有权；产品名仍为 TP。Windows 使用 `%APPDATA%\TP`，macOS 使用 Tauri 对应的应用数据根目录下的 `TP`。

新目录不存在数据库且旧目录存在数据库时，首次启动复制旧数据库与 assets，并改写文件副本的 stored 路径；原文件路径、记录身份、收藏、分组与设置保持不变。SQLite 使用 VACUUM INTO 包含已提交的 WAL 数据，在临时目录内完成附件复制、路径更新和完整性检查后才发布新目录。失败则停止启动，保留旧数据，不退回空数据库。新目录非空但没有数据库时拒绝覆盖；新数据库已存在时不重复导入。旧数据保留供用户确认后自行处理。

Windows 与 macOS 共用迁移实现。更改标识会改变系统识别应用的身份；既有 EXE/MSI 切换仍应先备份、卸载旧包并保留数据，再安装新包。macOS 的签名、公证、系统权限和安装行为需要在 Mac 上单独验证，不能由 Windows 验证结果推定。
