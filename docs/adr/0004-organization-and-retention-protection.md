# 收藏与分组表达保留意图，置顶只决定排序

“默认”和“收藏”是视图，收藏是独立标记，每条记录最多属于一个自建分组且可以同时收藏；这样无需在收藏与分类之间二选一。只有既未收藏又未分组的普通记录参与自动清理，记录置顶只影响排序而不提供保留保护，避免把临时排序与长期保留混为一谈。普通记录按最后使用时间及数量保留，来自 1Password 桌面应用的记录另有每条独立的敏感到期时刻，收藏或分组同样能阻止其自动删除。

## 后果

取消收藏、移出分组或删除分组后，失去全部保护的记录会立即重新接受自动清理检查，可能当场被删除，即使仍然置顶。应用记录只更新最后使用时间，不重置敏感到期时刻，因此刚应用过的普通敏感记录仍可能很快到期；收藏或分组则可以使它超过原定时刻继续保留。
